# Оцифровка логов скважин и проверка .improj

Проект: `D:\projects\well-curves`. Python: `.venv\Scripts\python`, перед командами `$env:PYTHONPATH="src"`.
Главное правило — **не выдумывать данные**. Чего не видно на скане — так и сказать.

## Предметная область (по регламенту и эталонам РЕ-БУЛАК)
- Работа в Kaiten: «В работе» → «На проверку» → «Проверяется» → «Готово». Оплата только за «Готово».
- Два направления: **TIFF-логи** (кривые по глубине) и **PDF-траектории** (30 сом за траекторию, примеров пока нет).
- Сдаётся файл **`.improj`** программы SoloImageAnalyzer. Формат разобран в `src/wellcurves/improj.py` (docstring).
- Глубины в **футах**. Масштабы: 1"=100', 1"=50' (30 сом/1000 ft), 1"=20' (45 сом/1000 ft); каждая кривая оплачивается отдельно.
- Сканы обычно **чёрно-белые**: кривые отличаются положением в дорожке и типом линии (сплошная/пунктир), а не цветом.
  Цвет в .improj — это цвет отрисовки оцифрованной кривой.
- Кривые: GR/Gamma (0–150 API, часто с перехлёстом 150–300), ROP (ft/hr, иногда шкала справа налево 500..0),
  сопротивления RLA1–5, плотность RHOZ, нейтрон TNPH (0.45..-0.15), PEFZ, кавернометр, инклинометрия, WOB, температура.
- **Перехлёст (MultiplierLevels)**: когда кривая уходит за правый край, она рисуется снова слева на следующем уровне
  шкалы (уровень 2 = 150..300). Точки такого участка помечаются `MultiplierLevel = 2`.
- **Intermediate-точки рамки**: на длинном скане дорожка «уезжает» — оцифровщик ставит пары левый/правый край
  на промежуточных глубинах. Без них значения на середине скана смещаются.
- Repeat Section — повторный замер в конце лога, оцифровывается отдельной рамкой.

## Автообводка (главный сценарий: «вот скан — обведи все кривые»)
1. `crop <скан> --rows 0:3000` → посмотреть шапку (Read): названия кривых, шкалы min–max, уровни, цвет/тип линии.
2. `layout <скан> --rows <y0:y1>` → края дорожек (вертикальные линии) и шаг толстых линий сетки (10 ft).
3. `crop` около двух подписанных глубин → строки для `depth.ref` (программа подтянет к центру линии).
4. Задание `data/jobs/<API>.json` по образцу `data/jobs/hosek_2.json` (формат — docstring `src/wellcurves/pipeline.py`):
   цветная кривая → `"color": [r,g,b]` по легенде; чёрная → `null`; пунктир/тонкая → `"stroke": 1, "clean": false`;
   уровни → `"wrap": [[150,300],...]` (диапазон уровня — как подписан на изображении, может быть неравномерным).
5. `auto data/jobs/<API>.json` → `output/<API>/`: `colored.png` + `colored_pages/` (белый фон, каждая кривая своим
   цветом, нарисовано ИЗ ЧИСЕЛ), `overlay/` (обводка поверх скана, окна по 200 ft), `curves.las`, `curves.csv`, `auto.improj`.
6. Открыть 3+ окна `overlay/` и проверить; затем `check output/<API>/auto.improj`.
Точность на эталоне 2.tif (Gamma): медиана 0.3 API, 95% точек ближе 1.5 API. Ограничение: две кривые
одного цвета в одной дорожке (напр. Amplitude и Amplified Amplitude) могут путаться — проверять overlay.

**Несколько чёрных кривых в одной дорожке (сплошная + пунктир + температура)** — сразу работать по шаблону
`references/template-black-multicurve.md` (режим по толщине штриха: `width`, `core`, `style`). Настройки проверять
на готовой задаче из базы: `tools/eval_width.py`.

## База знаний
`kb/docs/kaiten-rules.md` (правила, гид, проблемы API/TIFF), `kb/board-analysis.md` (854 выполненные задачи:
кривые, масштабы, типичные замечания проверяющих). Перед проверкой/сдачей пройтись по чек-листу замечаний оттуда.

## Команды
```powershell
python -m wellcurves auto   data/jobs/<API>.json           # автообводка всех кривых скана
python -m wellcurves layout <скан> --rows 3000:8000         # края дорожек и шаг сетки
python -m wellcurves crop   <скан> --rows 0:3000            # кусок длинного скана для просмотра
python -m wellcurves check  <файл.improj>                 # автопроверка перед сдачей: ошибки, пропуски, масштаб, оплата
python -m wellcurves improj <файл.improj> [--from 7000 --to 7150]  # сводка, LAS/CSV, overlay.png с наложением на скан
python -m wellcurves grid   <скан>                         # сетка пикселей для поиска координат рамки
python -m wellcurves colors <скан>                         # цвета на цветном скане
python -m wellcurves run    data/jobs/<задание>.json       # оцифровка цветных кривых по цвету (для цветных сканов)
```
Скан ищется рядом с .improj по имени файла (путь внутри проекта — с чужого компьютера).

## Сценарий А: проверить готовый .improj (роль проверяющего)
1. `check` → разобрать `errors` (блокирует сдачу) и `warnings`.
2. `improj --from --to` на 2–3 окна (начало, середина, конец, места с предупреждениями) → открыть `overlay.png`
   (Read) и глазами сверить: линия лежит на кривой скана, рамка совпадает с краями дорожки, глубины совпадают с отметками.
3. Ответить списком замечаний в стиле комментария Kaiten: глубина, что не так, как исправить.

## Сценарий Б: оцифровать новую кривую по задаче
1. Задача: скан, кривая, интервал (например Gamma, 6950–8950 ft).
2. Найти рамку: `grid` + просмотр скана (Read кусками: картинки до ~200 000 px в высоту, смотреть окнами).
   Углы рамки = край дорожки на верхней и нижней глубине интервала. Значения Left/Right — по шкале в шапке трека.
3. Цветной скан — `run` по цвету. Ч/б — автообводка пока в разработке: сейчас делаем вручную в SoloImageAnalyzer,
   а инструмент используем для проверки (`check` + `overlay`).
4. Сохранить .improj, название — Фамилия Имя исполнителя.

## Правила
- Не трогать исходные сканы и эталоны в `data/reference/`.
- Любой вывод о значениях подтверждать overlay-картинкой.
- Перед словами «готово к сдаче» — `check` без ошибок и просмотр overlay.

## Сомнительные места и редактор (после автообводки)
- `python -m wellcurves doubts <файл.improj>` — где обводка могла ошибиться → `<имя>.doubts.json`.
  Причины: непокрытые чернила (срезан пик / пропущен кусок), линия по пустому месту, пропуск, кривые вплотную,
  прижата к краю, смена уровня. Надёжно, когда в дорожке оцифрованы все кривые.
- `python -m wellcurves edit <файл.improj> [--port 8765]` — редактор в браузере (127.0.0.1): скан + кривые + список
  сомнений; «Рисовать» — провести участок заново, «Стереть» — сделать пропуск; N/P — след./пред. сомнение,
  Пробел — «проверено», Ctrl+Z, Ctrl+S. Сохраняет `<имя>.edited.improj` и `edited/curves.las|csv`.
- MCP `wellcurves`: `find_doubts`, `editor_open`. Несколько чёрных кривых в дорожке: поля задания `style`
  (solid/dashed/thin), `smooth`, `jump_cost`, `x_range`, порядок кривых = порядок обводки (см. `kb/docs/curve-math.md`).
- `python -m wellcurves verify <auto.improj> <эталон.improj>` — точность в % шкалы.
